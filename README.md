# Hi, I'm Giovanni 👋

I've been building software since 1997, when I was one of the first web developers in Italy.
Today I work AI-first: agents write the code, I decide what to build, how, and what goes to production.

## What I'm building

  The operating system for restaurants: menu, orders, kitchen and payments in one platform, rebuilt in 2025 on an AI-first model.
  1.8M+ orders a month, 99.9% uptime, hosted in the EU.
- **[Finis](https://getfinis.com)**: the app for writing your book on Mac and iPad.
  Native in SwiftUI, with Virgil, an AI editorial assistant that works only when you ask. Every book is a folder of plain Markdown files.
  Designed and built on my own.
